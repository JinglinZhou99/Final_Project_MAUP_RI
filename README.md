# Final_Project_MAUP_RI
Population data: based on the decennial census at the Census Block level on 2020 Census Redistricting Data: https://redistrictingdatahub.org/dataset/rhode-island-block-pl-94171-2020-by-table/

2020 County data: from 2020 Census Redistricting Data (P.L. 94-171) Shapefiles: 
https://redistrictingdatahub.org/dataset/rhode-island-county-pl-94171-2020/

State House District data: 2022 State House Approved Plan: 
https://redistrictingdatahub.org/dataset/2022-rhode-island-house-of-representatives-districts-approved-plan/

2020 election data: VEST 2020 Rhode Island precinct and election results: 
https://redistrictingdatahub.org/dataset/vest-2020-rhode-island-precinct-and-election-results/

2018 election data: VEST 2018 Rhode Island precinct and election results: 
https://redistrictingdatahub.org/dataset/vest-2018-rhode-island-precinct-and-election-results/
